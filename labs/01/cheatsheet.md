# Markdown Cheat Sheet

## Text

### Italic and bold

One star for italic, two for bold, three for both

```
*italic*, **bold**, ***both***
```
*italic*, **bold**,***both***

### Escaping a character

A backslash shows a special character literally instead of formatting.

```
\*not italic\*
```
\*not italic\*

### Headings

A heading is marked with a `#` followed by a space and then the text. You can use one to six hashtags for different level of the Heading

```
#### This is a heading!
```
#### This is a heading!

### Paragraphs and line breaks

A Paragraph starts when using an empty line. Text, empty line, Text. A backslash force a line break inside a paragraph
```
First line\
second line, same paragraph

A new paragraph.
```
First line\
second line, same paragraph

A new paragraph.

### Strikethrough

Two tildes on each side cross text out
```
~~no longer true~~
```
~~no longer true~~

### Inline Code

Backticks mark code inside a sentence; Markdown inside them is not interpreted
```
Run `pd.read_csv()` to load a file.
```
Run `pd.read_csv()` to load a file.

## Lists

### Unordered, ordered and nested lists
`_` or `*` for buttel points, `1.` for numbered items; indent to nest
```
1. Obtain
   - open data
   - web scraping
2. Scrub
```
1. Obtain
   - open data
   - web scraping
2. Scrub

### Task Lists

`[ ]` and `[x]` after a list marker make checkboxes.
```
- [x] Lab repository
- [ ] Cheat sheet
```
- [x] Lab repository
- [ ] Cheat sheet
